# 학습 라벨: 선생 증류와 구조물 빼기

로봇용 클래스 없는 분할 모델의 정답 마스크를 어떻게 만드는지에 대한 결정 기록이다.
(2026-10-10 ~ 10-11, 사용자와 함께 사진을 보며 정함. 근거 그림은 바탕화면 `구조물_판정*.jpg`, `유형_*.jpg`.)

## 1. 목표

- 클래스 구분 없이 **물체를 모두** 자른다. 물체 하나에 마스크 하나(부분으로 쪼개지 않음).
- **구조물은 자르지 않는다**: 벽, 천장, 바닥(도로·잔디·흙·모래 등 땅 포함), 하늘, 건물(집·지붕 포함).
- 카펫·러그, 물(바다·호수)은 물체로 둔다. 문·창문·계단도 물체다.
- 로봇이 집을 물체를 찾는 데 쓰므로 작은 물체를 놓치지 않는 것이 중요하다.

## 2. 왜 선생 모델인가

COCO 사람 라벨만으로는 부족하다.
- 물체 80 종 밖의 물건은 개체 라벨이 없다.
- stuff 53 종은 개체 구분 없는 덩어리다. 선반 위 물건이 선반에 섞여 칠해지고, 떨어진 창문 셋이 마스크 하나다.

그래서 정답 마스크는 **CropFormer Hornet-L**(개체 분할, 코드·가중치가 공개된 모델 중 EntitySeg 점수 최고)로 만든다.
COCO 사람 라벨은 "어느 마스크가 구조물인가"를 판단하는 데만 쓴다. 선생에 대한 자세한 내용은 [TEACHER.md](TEACHER.md).

- 선생은 원본 그대로(화면 다섯 장) 돌리고 C++/CUDA fp16 으로 옮겼다(원본 PyTorch 와 fp32 에서 같음).
- 학습 사진 118,287 장 모두 라벨을 만들었다(`data/teacher/train2017.ftl`, 약 7 시간). 사진당 점수 0.5 이상 마스크 평균 25.7 개.
- 사진의 화소는 모두 선생 마스크 하나에 속한다(겹치지 않음). 점수 0.5 미만 마스크는 쓰지 않는다.

## 3. 마스크마다 판정

같은 사진의 COCO panoptic 사람 라벨에서 구조물 = 배경 22 종
(벽 5, 천장 1, 바닥·땅 12, 하늘 1, 건물 3: building-other-merged, house, roof).

| 경우 | 조건 | 처리 |
|---|---|---|
| 1. 물체 | 마스크 화소 중 COCO 구조물이 50 % 미만 | 물체 정답 |
| 2. 큰 구조물 | 구조물 50 % 이상이고, 가장 많이 겹치는 COCO 구조물 조각의 30 % 이상을 덮음 | 정답에서 뺀다 |
| 3. 구조물 + 물체가 합쳐짐 | 2 번인데 COCO 물체 화소가 20 % 이상 섞임 (벽+문, 바닥+카운터 등) | 구조물 부분만 빼고, 섞인 COCO 물체 조각을 (떨어진 조각마다) 물체 정답으로 남긴다. 사진의 0.1 % 보다 작은 조각은 무시 영역 |
| 4. 작은 구조물 후보 | 구조물 50 % 이상이지만 2 번에 못 미침 (벽 틈, 바닥 조각, 액자·스위치 등) | SigLIP2 로 마스크 조각을 보고 구조물 확률 합(벽+천장+바닥+하늘) ≥ 0.8 이면 뺀다, 아니면 물체 |

- 4 번에서 확률을 합으로 보는 이유: 벽·천장·바닥은 서로 비슷해 한 갈래의 확률이 0.8 에 못 미칠 수 있다. 어느 구조물인지는 COCO 라벨이 정한다.
- 기준을 높게(0.8) 둔 이유: 진짜 물체가 빠지는 쪽이 벽 조각이 남는 쪽보다 로봇에 나쁘다.
- SigLIP2 모델: `google/siglip2-giant-opt-patch16-384`(공개 SigLIP2 중 가장 큼). 마스크 상자를 정사각형으로 잘라 마스크 밖은 회색으로 덮는다.

**빈틈**: COCO 가 물체로 칠했는데 어느 정답 마스크에도 덮이지 않은 화소(관중석의 사람 무리, 빽빽한 진열대 등)는
**무시 영역**: 물체라고도 배경이라고도 가르치지 않는다.

## 4. 전체 점검 결과 (118,287 장, 점수 ≥ 0.5 마스크 3,035,844 개)

| 유형 | 마스크 | 사진 | 사진을 보고 내린 판단 |
|---|---|---|---|
| 큰 구조물(경우 2) | 207,443 | 83 % | 정상, 뺀다 |
| 구조물+물체 합쳐짐(경우 3) | 13,475 | 10.5 % | COCO 로 나눈다 |
| 작은 구조물 후보(경우 4) | 558,577 | 66 % | 표본 실내 사진에서 약 16 % 가 진짜 벽·바닥 조각, 나머지는 물체 → SigLIP2 |
| 물체 마스크가 구조물로 조금 샘(구조물 20~50 %) | 198,480 | 55 % | 대부분 경계의 작은 마스크 → 그대로 |
| 한 마스크가 COCO 물체 둘 이상을 덮음 | 14,344 | 10 % | 쌓인 책·컵 등 작은 것 → 그대로 |
| COCO 물체 하나가 선생 마스크 여러 개로 | 8,068 | 6 % | COCO 쪽이 틀린 경우가 많음(의자 라벨이 고양이까지 덮음, 스키 한 쌍, 오븐+냄비) → 선생을 따른다 |
| 빈틈 | 사진당 중앙값 0.43 %, 20 % 넘게 빈 사진 795 장 | | 무시 영역 |

덮인 비율(점수 ≥ 0.5): COCO 물체 화소 98.8 %, 기타 물체 99.0 %, 구조물 99.5 %.

## 5. 학습할 때 쓰는 방법

- 선생 라벨 파일은 그대로 둔다. 사진마다 "뺄 마스크, 나눠서 살릴 물체 조각, 무시 영역, SigLIP2 후보"를 **한 번 계산해 작은 판정 파일**로 저장한다.
- 학습기 데이터 로더가 COCO 사진 + 선생 라벨 + 판정 파일을 바로 읽어 정답을 만든다(따로 묶은 학습용 파일을 만들지 않는다).
- 무시 영역은 증강(모자이크·크기·이동·뒤집기)에서 정답 마스크와 똑같이 옮기고, 그 안의 앵커에는 물체 점수 손실을 주지 않는다.

## 6. 그 밖의 결정

- 출발 가중치: YOLOv8s-seg(COCO)에서 클래스 출력층만 80 → 1 로 새로 초기화. FastSAM-s 는 SAM 이 자동으로 만든
  SA-1B 정답지(부분 마스크가 섞인 과분할)로 배워 쓰지 않는다.
- 라이선스: 연구용. CropFormer(CC BY-NC 4.0), COCO 사진(Flickr, 일부 비상업), YOLOv8s-seg(AGPL-3.0) → 결과 모델도 비상업 연구용, AGPL.
