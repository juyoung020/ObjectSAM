## 2. 평가 방법

- **uHumans2 는 학습에 절대 쓰지 않는다**(학습 분포 밖 평가). 오류 분석은 방향만, 규칙은 일반 원리로.
- 데이터: uHumans2 apartment_00h·01h·02h, office_00h·12h(office_06h 는 내려받기 실패로 빠짐).
- 절차: Meridian frontend 벤치마크(`~/meridian_ws/src/meridian/benchmarks/meridian_benchmark/frontend_benchmark/eval.sh`) 그대로, SAM 엔진(1024 ONNX → TensorRT)과 문턱 `MERIDIAN_SAM_CONF_TH` 만 바꾼다. 문턱은 **0.1·0.4 두 가지만**, 확신도 보정 없음.
- **주 채점 = 물체 기준 평가** `source ~/meridian_ws/tools/env.sh; python3 ~/meridian_ws/tools/obj_eval.py 이름=runs/폴더[:시퀀스,시퀀스] ...`
